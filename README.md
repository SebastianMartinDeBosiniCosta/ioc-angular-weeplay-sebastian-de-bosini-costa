# WeePlay

## Autor/a

Sebastian Martin De Bosini Costa

## Descripción

WeePlay es una plataforma digital orientada al fútbol amateur
que conecta jugadores, equipos y propietarios de canchas.
Su objetivo es facilitar la organización de partidos y
fomentar la práctica amateur del deporte.

## Versiones utilizadas

- Node.js: v24.18.0
- npm: 11.16.0
- Angular CLI: 22.2.2
- Angular: 22.2.2
- Git: 2.51.0.

## Cómo crear y ejecutar el proyecto

Comando de creación utilizado:

```powershell
ng new ioc-angular-weeplay-sebastian-de-bosini-costa --routing --style=scss --ssr=false --standalone --file-name-style-guide=2016 --skip-git --package-manager=npm
```
